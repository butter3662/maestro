# Maestro — 틀린 단원을 찾아라

오케스트라 연주를 들으면서 미묘하게 틀리게 연주하는 단원을 찾아내는 웹 게임.

- **찾기**: 음정·박자·셈여림·입장 미스를 낸 단원을 탭하면 보너스. 음정은 쉬움 반음·보통 반의 반음·어려움 반의 반의 반음, 박자는 쉬움 반 박·보통 반의 반 박·어려움 반의 반의 반 박 어긋난다.
- **보너스**: B = B<sub>0</sub>·k·(1 − Δt/T)² — 틀린 소리가 난 뒤 빨리 잡을수록(Δt가 작을수록) 크게 오른다.
- **점수**: S = ΣB<sub>i</sub> − n<sub>f</sub>·P (B<sub>i</sub>: 적발 보너스, n<sub>f</sub>: 오지적 횟수, P: 오지적 감점)
- **곡 (20곡)**: 일반 16곡(녹턴 Op.9 No.2 포함) + 👑 보스 4곡(쇼팽 혁명 에튀드·에튀드 Op.10 No.1·흑건, 베토벤 월광 소나타 3악장). 일반 곡: 환희의 송가, 엘리제를 위하여, 사계 「봄」, 아이네 클라이네 나흐트무지크, 카논, 터키 행진곡, 백조의 호수, 꽃의 왈츠, 아름답고 푸른 도나우, 캉캉, 헝가리 무곡 5번, 산왕의 궁전에서, 아침 기분, 신세계 교향곡 2악장, 죽음의 무도 — 모두 저작권이 끝난 곡. 선율은 flutetunes.com 공개 플루트 악보로 음을 확인했고 화성·반주는 게임용으로 단순화했다.
- **난이도**: 쉬움 3명 / 보통 5명 / 어려움 11명
- **공간 음향**: 이어폰 착용 시 HRTF 3D 배치

단일 파일(`index.html`)로 동작하며 외부 라이브러리가 없다.
