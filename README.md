# Maestro — 틀린 단원을 찾아라

지휘하면서 미묘하게 틀리게 연주하는 단원을 찾아내는 웹 게임.

- **지휘**: 박마다 지휘대를 탭한다. 탭 간격이 템포, 탭하는 높이가 셈여림(위 ff ~ 아래 pp)이 된다. 오케스트라는 지휘자의 박을 따라오고, 박이 안 오면 기다린다.
- **찾기**: 음정(센트 단위 어긋남)·박자·셈여림·입장 미스를 낸 단원을 탭하면 보너스.
- **점수**: S = S<sub>c</sub> + ΣB<sub>i</sub> − n<sub>f</sub>·P
- **곡**: 파헬벨 「카논」, 차이콥스키 「꽃의 왈츠」, 생상스 「죽음의 무도」 (게임용 편곡, 브라우저 실시간 합성)
- **난이도**: 쉬움 3명 / 보통 5명 / 어려움 11명
- **공간 음향**: 이어폰 착용 시 HRTF 3D 배치

단일 파일(`index.html`)로 동작하며 외부 라이브러리가 없다.
